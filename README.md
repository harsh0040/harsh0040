## 🚀 Selected work

### Eleno — Leadership Operations Tool
Internal ops app for an AI &amp; automation consultancy. Tracks billable vs total
hours per engineer, per client, per fortnight, so leads watch utilisation targets,
approve timesheets, and manage finance — replacing manual spreadsheet ops.
- **Role:** built end to end — role-gated engineer/lead views, timesheet
  submit/approve flow, ClickUp sync, Excel export.
- **Stack:** Next.js · TypeScript · Supabase · ClickUp API · Playwright
- 📊 [Architecture writeup →](https://github.com/harsh0040/eleno-architecture) &nbsp;·&nbsp; _private repo (company work)_

### Eleno — Marketing Site &amp; Studio
Marketing site for Eleno. Leads with proven consulting work, then introduces the
subscription platform. Team edits everything through a Studio embedded in the app.
- **Role:** built the site, the Sanity content model, and the lead-capture pipeline.
- **Stack:** Next.js · Sanity CMS · Portable Text · Resend
- 📊 [Architecture writeup →](https://github.com/harsh0040/eleno-architecture) &nbsp;·&nbsp; _private repo (company work)_

### Wayfynd — Sensory-budget route scoring
Scores walking routes in the Melbourne CBD by *sensory cost*, not just time, using
City of Melbourne open data. Warns commuters before a crowd surge reaches them and
points to a nearby quiet refuge.
- **Role:** full monorepo — React SPA, Express API, and a nightly ETL job that
  fetches and upserts the open datasets on a schedule.
- **Stack:** React (Vite) · Node/Express · PostgreSQL 16 + PostGIS (RDS) ·
  AWS (S3/CloudFront + EC2, EventBridge) · Turborepo/pnpm

### Weekly Budget &nbsp;·&nbsp; [🔗 Live](https://supabase-sync-rouge.vercel.app)
A zero-dependency budgeting web app: one `index.html`, no build step. Plan income by
bucket into weekly figures, log expenses against a weekly ideal, roll weeks up into a
monthly trend. Backup/restore to JSON.
- **Role:** designed and built it, including the fortnightly pay-cycle logic and a
  later Supabase-backed sync build.
- **Stack:** vanilla HTML/CSS/JS · localStorage · Supabase · Vercel
